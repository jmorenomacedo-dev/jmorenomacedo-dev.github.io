Política de Privacidade — Jarvis Neto

Última atualização: 20 de outubro de 2026

1. Quem somos

O Jarvis Neto é um app de uso pessoal de Jorge Moreno Macedo (JM Agency), Natal/RN, Brasil.

2. Dados acessados

O app acessa apenas dados dos canais do YouTube do próprio titular, via APIs do Google, com os escopos de leitura youtube.readonly e yt-analytics.readonly: visualizações, tempo de exibição, inscritos, curtidas, comentários e lista de vídeos. O app não tem nenhuma permissão de edição, envio ou exclusão.

3. Uso dos dados

Os dados são usados para gerar relatórios internos de desempenho dos canais. Nada mais.

4. Armazenamento

Os tokens de acesso e os relatórios ficam somente no computador do titular. Nada é vendido, compartilhado ou transferido a terceiros.

5. Conformidade

O uso das informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

6. Revogação

O acesso pode ser revogado a qualquer momento em https://myaccount.google.com/permissions.
